# Receptes de la mama

Receptari familiar instal·lable (PWA), en català.

## Funcions inicials
- Afegir, editar i eliminar receptes.
- Categories, cercador i favorits.
- Fitxa de recepta i mode cuina pas a pas amb temporitzadors.
- Llista de la compra i menú setmanal.
- Importació de receptes des d'URL quan la web permet accés des del navegador.
- Dades desades localment al dispositiu i memòria cau per ús offline.

## Publicació
A GitHub, ves a **Settings → Pages** i selecciona **Deploy from a branch**, branca **main** i carpeta **/(root)**. La web quedarà publicada a:
https://cathalmcdonegal.github.io/Receptes-de-la-mama/

Les receptes es desen al navegador del dispositiu. Exportació/còpia de seguretat i sincronització familiar són millores previstes per a una següent fase.
